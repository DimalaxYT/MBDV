Espace associés

Cibler les entreprises sans site web, puis les convertir.

MBDV interroge la base officielle des entreprises françaises (INSEE / RNE), vérifie automatiquement la présence d'un site web pour chacune, et met en évidence celles qui n'en ont pas — vos prospects. Un portefeuille partagé suit ensuite le cycle commercial, et un journal staff garde la trace de chaque entreprise écartée.

Comment ça marche

01 · Rechercher

Filtrer la base officielle

Dénomination, activité, SIREN, département, code postal, grand secteur, code NAF précis, tranche d'effectif. Les données viennent de l'API recherche-entreprises.api.gouv.fr : rien n'est inventé.

02 · Détecter

Chercher un site web

Pour chaque entreprise, l'outil construit les domaines probables à partir de la raison sociale et de l'enseigne (en .fr, .com, .net) puis tente une résolution DNS. Un domaine qui répond est un indice fort d'un site existant.

03 · Vérifier

Confirmer à la main

La détection reste un indice : depuis la fiche, Revérifier relance l'analyse et Confirmer sans site verrouille votre certitude. Les résultats sont mis en cache 30 jours.

04 · Écarter

Masquer avec un motif

Doublon, entreprise déjà équipée, hors cible, déjà contactée… Chaque masquage demande une raison et alimente le panel staff : auteur, date, précisions, remise d'affichage éventuelle.

05 · Suivre

Faire avancer le portefeuille

06 · Exporter

Sortir les données

Export CSV de la page de résultats (format Excel français, séparateur ;) : coordonnées, activité, effectif, dirigeants, état du site détecté et statut commercial.

Dans une fiche entreprise

  • Identification — SIREN, SIRET du siège, forme juridique, date de création, établissements.
  • Localisation — adresse du siège, département, région, repérage sur carte.
  • Activité — code NAF et libellé, tranche d'effectif, début d'activité.
  • Dirigeants — nom, qualité, année de naissance (source INPI).
  • Finances — dernier chiffre d'affaires et résultat net publiés.
  • Repères — RGE, Qualiopi, bio, ESS, société à mission, association…

Bon à savoir

  • Aucune donnée inventée. Si la base officielle est injoignable, l'outil le dit et n'affiche rien. Un jeu de démonstration (entreprises fictives) n'est servi que sur demande explicite, et toujours annoncé comme tel.
  • La détection est heuristique. Un site peut exister sous un domaine imprévisible ; un domaine peut répondre sans héberger de site. D'où la vérification manuelle en un clic.
  • Deux accès distincts — chacun son identifiant et son mot de passe, un portefeuille commun. Les mots de passe sont stockés hachés (scrypt).
  • Sessions et écritures protégées — jeton CSRF sur chaque enregistrement, sessions signées, limitation des tentatives de connexion.
